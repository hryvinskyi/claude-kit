# Review rules — acme-library

## Classes

- S — wording, a test-only change.
- M — a new module or a change to one module's logic.
- L — money, a member's record, or more than one module.

## What to report

- A fee, a refusal or a date count that is wrong for any input a member can reach.
- A test whose name claims a behaviour its body does not exercise.

## Do not report

- Style the code already follows elsewhere.
- That there is no linter or type check: the project chose that.

## Where reviews here have missed

- none recorded
